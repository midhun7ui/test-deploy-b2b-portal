HireD – B2B Portal Feature List
Here is the proposed feature list for your HireD B2B Partner Portal, organized by modules for frontend development.

1. Dashboard
- Total orders
- Pending orders
- Accepted and rejected orders
- Ongoing trips
- Completed trips
- Monthly spending summary
- Recent activities
- Notifications overview

2. Order Management
- Create new logistics orders
- Submit orders for admin approval
- View all orders
- View order details
- Track order status
- View accepted and rejected orders
- View rejection reasons
- Filter and search orders
- View order history

3. Trip Management
- View trips created from accepted orders
- View trip details
- View assigned driver information
- Track trip status
- View trip start and completion times
- View trip history
- View trip progress updates

4. Trip Reports
- View completed trip reports
- View trip details and route information
- View trip expenses, where permitted
- View driver and trip summaries
- Filter reports by date
- Download trip reports, if supported

5. Invoices & Statements
- View monthly statements
- View published invoices
- View invoice details
- View completed-trip charges
- View billing periods
- Download invoices, if supported
- View payment status

6. Company Profile
- View company details
- View registered address and contact information
- View company account information
- Update permitted profile details
- View company-specific settings

7. Notifications
- Order accepted or rejected notifications
- Driver assignment updates
- Trip status notifications
- Trip completion notifications
- Invoice publication notifications
- Important account notifications

- Notification history
8. Reports & Analytics
- Monthly order reports
- Trip completion summaries
- Monthly spending analytics
- Order status breakdown
- Date-range filtering
- Export reports, if supported

9. Authentication & Security
- Partner login and logout
- Password reset
- Change password
- Session management
- Company-scoped data access
- Role-based permissions

10. Support
- Contact admin
- Submit support requests
- View support request history
- Report order or trip issues
